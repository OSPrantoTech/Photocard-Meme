# Photo Card Generator by OSPranto Tech

"Technology with a Sense of Ease"

A web-based tool for creating beautiful, customizable photo cards and social media graphics.

## Features
- Multiple professionally designed templates.
- Full Bengali language support.
- Custom branding and logo integration.
- High-quality PNG export.
